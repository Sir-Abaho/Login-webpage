# MUST Application Pages

A simple HTML and CSS project with login and account creation pages inspired by the MUST application portal.

## Pages

- `index.html` — Login page
- `create-account.html` — Create-account page
- `style.css` — Shared page styles

## View the pages

Open `index.html` or `create-account.html` in a web browser. No installation is required.

The forms are for demonstration only and do not save or submit account information.
